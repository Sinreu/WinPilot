# ◈ WinPilot

**WinPilot** — бесплатный, локальный оптимизатор и помощник по обслуживанию **Windows 11** с графическим интерфейсом на русском языке. Без рекламных предложений, телеметрии, подписок и «волшебных» твиков.

> Версия 1.0.1 (MVP). Исходный код доступен целиком; исполняемый файл пока не подписан цифровой подписью.

## Возможности

| Раздел | Действия | Безопасность |
| --- | --- | --- |
| Обзор | Версия Windows, свободное место, uptime, число записей автозагрузки | Только чтение |
| Очистка | Сканирование `%TEMP%` и удаление файлов старше 24 часов | Превью, подтверждение, пропуск занятых файлов и ссылок |
| Автозагрузка | Просмотр `HKCU`/`HKLM` Run, отключение **только HKCU**, восстановление | Резервная копия команды и типа параметра |
| Настройки | Анимации окон, прозрачность, Game DVR | Каждое изменение вручную и с откатом |
| Питание | Выбор установленной в Windows схемы питания | Запоминает прежнюю схему |
| Диагностика | Открыть штатные параметры автозагрузки, сбросить кэш DNS | Запрос подтверждения |
| Журнал | История операций и ошибок | Локальный файл `%LOCALAPPDATA%\WinPilot\operations.log` |

## Установка / запуск

### Вариант 1. Запуск исходного кода

Нужны Windows 11 и **Python 3.12** с Tkinter (обычно включён в установщик Python).

```powershell
cd WinPilot
py -3.12 app.py
```

Администратор **не требуется** для типичных действий программы. Windows может ограничить отдельные операции средствами политик организации.

### Вариант 2. Сборка EXE на Windows

```powershell
cd WinPilot
powershell -ExecutionPolicy Bypass -File .\Build-Windows.ps1
```

Готовый portable-файл: `dist\WinPilot.exe`. Для запуска exe Python на целевом компьютере не нужен. PyInstaller устанавливается отдельно для сборки.

### Вариант 3. GitHub Actions

1. Загрузите содержимое проекта в GitHub.
2. Перейдите во вкладку **Actions** → **Build Windows EXE** → **Run workflow** (либо отправьте коммит в `main`).
3. Скачайте артефакт **WinPilot-Windows** с готовым `.exe`.

### Публикация в GitHub одним скриптом

Установите [Git for Windows](https://git-scm.com/download/win) и [GitHub CLI](https://cli.github.com/), затем в терминале:

```powershell
gh auth login
powershell -ExecutionPolicy Bypass -File .\Publish-GitHub.ps1 -Repository WinPilot
```

Скрипт создаст **приватный** репозиторий в вашем аккаунте GitHub, закоммитит файлы и отправит ветку `main`. Чтобы сделать репозиторий публичным позже, поменяйте его видимость в настройках GitHub. Не используйте токены в коде или репозитории.

## Рекомендации по безопасному использованию

- **Оптимизатор не обещает прибавку FPS**. Отключение анимации и прозрачности в основном влияет на интерфейс; записи Game DVR — на фоновый захват.
- Выключение записи Game DVR отключает часть возможностей захвата и сохранения клипов Xbox Game Bar.
- Отключайте в автозагрузке только знакомые приложения. Не трогайте незнакомые средства безопасности/драйверы.
- Очистка TEMP окончательна: файлы **не попадают в корзину**. Не запускайте очистку во время установки/обновления программ.
- Перед массовыми изменениями Windows рекомендуется создать точку восстановления средствами Windows. WinPilot сам её не создаёт.
- Никакие твики не применяются автоматически. Программа **не отключает** Windows Update, Defender, UAC, SmartScreen, журнал событий, службы Windows и не изменяет сетевой стек «ради ускорения».
- Состояние и резервные копии хранятся в `%LOCALAPPDATA%\WinPilot\state.json`. Для последующего отката не удаляйте этот файл.

## Тестирование

```powershell
py -3.12 -m unittest discover -s tests -v
```

Часть файловых тестов можно запустить и на других ОС; реестр Windows, интерфейс и готовый `.exe` требуют проверки на настоящем Windows 11.

## Структура

```text
WinPilot/
├─ app.py                     # Точка входа GUI
├─ winpilot/
│  ├─ core.py                 # Безопасные системные операции
│  └─ gui.py                  # Интерфейс Tkinter
├─ tests/test_core.py         # Тесты
├─ Build-Windows.ps1          # Сборка exe локально
├─ Publish-GitHub.ps1         # Публикация в GitHub (private)
└─ .github/workflows/
   └─ windows-build.yml       # Проверка и сборка EXE на GitHub Actions
```
